This project is using in memory database of EntityFramework for testing purposes. This implements folowing pattern:
	- Repository Pattern
	- Unit of Work Pattern
	- Specification Pattern

It also implements Global Exception Handling

But Specification Pattern is not necessary to implement with the Repository Pattern / Unit Of Work Pattern.

To run the project, follow these steps:
1. Clone the repository to your local machine.
2. Install Microsoft.EntityFrameworkCore.InMemory Nuget Package.
3. Open the solution in Visual Studio.
4. Build the solution to restore all NuGet packages.
5. Run the project using Visual Studio or your preferred IDE.
